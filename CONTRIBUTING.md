# Contributing

Issues and pull requests are welcome.

- The skill is a single `SKILL.md`. Keep it short and keep the rules, caps and red-flag rows consistent with each other.
- If you change a cap or a step, update the README ("The caps" and the workflow diagram) in the same PR.
- Keep `description` in the frontmatter at 1024 characters or fewer, with `name` and `description` present.
- Never put real paths, tokens or personal details in the repo.
- Keep the Safety section accurate: if a change weakens a guardrail, say so in the PR.
